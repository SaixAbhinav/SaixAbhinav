## Projects

### [SmartSignal](https://github.com/SaixAbhinav/smart-signal) — RL traffic signal control
PPO agent trained in SUMO and benchmarked against fixed-timer, actuated and max-pressure control: **~91% less waiting than a fixed timer**, and on a four-junction grid one shared policy beats max-pressure by **22–35%**.

### [Workflow Copilot](https://github.com/SaixAbhinav/Workflow_copilot) — local-first LLM assistant
Desktop assistant (PyQt5 + Ollama) that turns documents and Gmail into summaries, tasks and Calendar events — the LLM runs on-device, so documents and emails never reach a third-party AI service.

### [DermaScan](https://github.com/SaixAbhinav/DermaScan) — skin-lesion image classifier
MobileNet transfer-learning classifier for 7 skin-lesion types on HAM10000 (**87% accuracy**), served through a FastAPI web app with Grad-CAM heatmaps.

### [Fake Account Detector](https://github.com/SaixAbhinav/Instagram_fake_account_detector) — Instagram fake profile classifier
Stacked ensemble: a CNN on the profile picture and a Random Forest on profile metadata (posts, followers, following, follower-to-following ratio), combined by a logistic-regression meta-model.
